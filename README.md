# Astera USA

Astera is a German manufacturer of wireless, battery-powered LED lighting for film, TV, events, and creative applications.

Inner Circle Distribution is a U.S. distributor for Astera, supporting product availability, demos, service, education, and long-term customer relationships across North America, Latin America, and the Caribbean.
